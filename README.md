# External evidence folder

Put redacted, genuine evidence here only after the activity is performed:
- stakeholder walkthrough records (one per actual reviewer)
- CI benchmark JSON and logs from the real repository
- labelled critical-defect recall calculations
- staging deployment, restart, backup/restore, monitoring, and rollback evidence
- actual reviewer sign-off if provided

Do not add fabricated results or secrets. Keep pending gates marked pending until evidence exists.
